# WAVON — ระบบเช็คชื่อนักกีฬาข้างสนามผ่าน QR Code

เว็บแอปพลิเคชันสำหรับโค้ชและอคาเดมีกีฬา ช่วยให้การเช็คชื่อข้างสนามเป็นเรื่องง่าย เลิกใช้กระดาษจดหรือพิมพ์ตามในกลุ่มไลน์ นักกีฬาสามารถเดินมาสแกน QR Code ริมสนามเพื่อเช็คชื่อตัวเองได้ทันที พร้อมระบบสรุปสถิติและส่งออกรายงานเป็นไฟล์ Excel

---

## ฟีเจอร์หลัก

- **เช็คชื่อด้วย QR Code ริมสนาม:** ป้าย QR เดียวใช้ได้ตลอดฤดูกาล นักกีฬาเดินมาสแกนผ่านกล้องมือถือหรือแอป LINE แล้วค้นหาชื่อตัวเองเพื่อกดยืนยันได้ทันที ไม่ต้องสมัครสมาชิก
- **ระบบแจ้งลาซ้อม:** นักกีฬาหรือผู้ปกครองสามารถกดแจ้งลาล่วงหน้า พร้อมระบุเหตุผล (ลาป่วย, ติดสอบ, ธุระ) ได้จากที่บ้าน
- **คุมซ้อมแบบ Real-time:** โค้ชสามารถเปิดหน้าจอรอบซ้อมบนมือถือหรือแท็บเล็ตเพื่อดูยอดนักกีฬาที่มาซ้อมได้แบบสดๆ และสามารถช่วยกดเช็คชื่อให้เด็กที่ไม่ได้พกมือถือมาได้
- **ตัดรอบซ้อมอัตโนมัติ:** เมื่อหมดเวลาซ้อม ระบบจะปรับสถานะนักกีฬาที่ไม่ได้มาเช็คชื่อเป็น "ขาดซ้อม" ให้อัตโนมัติ โค้ชไม่ต้องมานั่งไล่เช็คย้อนหลัง
- **นำเข้ารายชื่อเป็นชุด:** สามารถคัดลอกรายชื่อนักกีฬาจากกลุ่ม LINE หรือไฟล์อื่นมาวางลงในช่องนำเข้าได้ทีเดียว ระบบจะตัดคำนำหน้าและจัดระเบียบข้อมูลให้เอง
- **ระบบสถิติและเกรดวินัย:** มีคะแนนความสม่ำเสมอ (Attendance Rate) และเกรดวินัยของนักกีฬา โดยการลาซ้อมอย่างถูกต้องจะไม่ถูกนำมาหักคะแนน
- **ส่งออกรายงาน Excel (.xlsx):** สร้างไฟล์ Excel สรุปสถิติแยกเป็น 4 แผ่นงาน (ภาพรวมสโมสร, สรุปรายเดือน, สรุปรายวัน, สถิตินักกีฬารายบุคคล) สามารถเลือกช่วงเวลาที่ต้องการส่งออกได้ ทั้งแบบทั้งหมด, เฉพาะวันนี้, รายเดือน, หรือกำหนดช่วงวันที่เอง
- **รองรับหลายสโมสร (Multi-Club):** โค้ชแต่ละสโมสรสามารถลงทะเบียนเปิดทีมของตัวเองได้ ข้อมูลของแต่ละทีมจะแยกจากกันอย่างชัดเจน

## สิทธิ์การใช้งานในระบบ

1. **นักกีฬา / ผู้ปกครอง:** ไม่ต้องมีบัญชีผู้ใช้ เพียงแค่สแกนป้าย QR เพื่อค้นหาชื่อและกดยืนยันเช็คชื่อ หรือเลือกแจ้งลาซ้อม
2. **โค้ช (Coach):** ล็อกอินเพื่อจัดการรายชื่อนักกีฬา สร้างรอบซ้อม พิมพ์ป้าย QR ขนาด A4 ประจำสนาม และดาวน์โหลดรายงาน Excel
3. **ผู้ดูแลระบบ (Admin):** จัดการภาพรวมของทุกสโมสร และมีเครื่องมือสำหรับสร้างหรือล้างข้อมูลตัวอย่าง (Demo Data)

## เทคโนโลยีที่ใช้

- **Framework:** Next.js (App Router) + React
- **Styling:** Tailwind CSS
- **Database & ORM:** SQLite / Turso LibSQL + Drizzle ORM
- **Testing:** Vitest
- **Deployment:** Render.com (หรือแพลตฟอร์มที่รองรับ Node.js)

## การติดตั้งและรันในเครื่อง (Local Development)

### 1. โคลนโปรเจกต์และติดตั้ง Dependencies

```bash
git clone https://github.com/tivakornchunkh/wavon-attendance.git
cd wavon-attendance
npm install
```

### 2. รันโหมดพัฒนา

```bash
npm run dev
```

เปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

### 3. การรัน Unit Tests

```bash
npx vitest run
```

### 4. การ Build สำหรับ Production

```bash
npm run build
```

## บัญชีทดสอบระบบ (Demo Accounts)

ในหน้าเข้าสู่ระบบ (`/login`) จะมีปุ่มลัดสำหรับเข้าใช้งานบัญชีทดสอบได้ทันที:
- **โค้ชอาร์ม (WAVON):** บัญชีตัวอย่างสโมสรหลัก
- **โค้ช THUNDER:** บัญชีตัวอย่างสำหรับทดสอบระบบแยกข้อมูลสโมสร
- **ผู้ดูแลระบบ (Admin):** บัญชีสำหรับจัดการทุกสโมสรในระบบ
