## 🌟 ภาพรวมและจุดเด่นของระบบ (System Overview)

**WAVON Athlete Attendance System** ได้รับการออกแบบและพัฒนาขึ้นเพื่อแก้ปัญหาความวุ่นวายของการเช็คชื่อนักกีฬาในสนามกีฬา ไม่ว่าจะเป็นฟุตบอล แบดมินตัน บาสเกตบอล วอลเลย์บอล หรืออคาเดมีศิลปะการต่อสู้ โดยเปลี่ยนจากการใช้กระดาษจดหรือการพิมพ์ในกลุ่ม LINE มาเป็น **Web-Based Athletic Attendance Platform** ที่ทำงานได้แบบเรียลไทม์ 100%

### จุดเด่นสำคัญ (Key Highlights):
- 🖨️ **Permanent QR Code:** พิมพ์ป้าย QR ขนาด A4 แปะติดสนามครั้งเดียว ใช้งานได้ตลอดทั้งฤดูกาล แก้ไขรอบซ้อมได้โดยไม่ต้องพิมพ์ QR ใหม่
- ⚡ **Lightning Fast Inline Check-In:** นักกีฬาเปิดกล้องมือถือหรือ LINE สแกนป้ายแล้วแตะชื่อเช็คชื่อสำเร็จใน 1 วินาที ไม่ต้องล็อกอิน ไม่ต้องโหลดแอป
- 👥 **Batch Roster Import:** คัดลอกรายชื่อ 20–50 คนจาก LINE หรือ Excel มาวางในช่องเดียว ระบบตัดคำ นำเข้า และสร้างรหัสให้อัตโนมัติในคลิกเดียว
- ⏱️ **Auto-Close & Auto-Absent:** เมื่อสิ้นสุดเวลาการฝึกซ้อม ระบบตัดยอดนักกีฬาที่ไม่ได้มาเป็น "ขาดซ้อม" ให้ทันทีโดยที่โค้ชไม่ต้องมานั่งไล่ติ๊กทีละคน
- 📊 **Pro Athletic Analytics:** แดชบอร์ดสรุปเปอร์เซ็นต์ความสม่ำเสมอ (Attendance Rate), ดัชนีสุขภาพสโมสร (Club Readiness Index Grade A-D), สัญลักษณ์ 5-dot Streak และส่งออกไฟล์รายงาน Excel สรุปรายเดือน/รายสัปดาห์
- 🏢 **Multi-Club Isolation:** รองรับการแยกข้อมูลสโมสรอย่างเด็ดขาด แต่ละสโมสรมีนักกีฬา รอบซ้อม และโค้ชดูแลแยกจากกัน
- 🛡️ **Pitch Anti-Cheat:** ป้องกันการกดเช็คชื่อทิพย์จากที่บ้าน โดยระบบตรวจสอบโทเคนสแกนจากป้ายจริงริมสนาม (หากเปิดจากลิงก์ที่บ้านจะอนุญาตเฉพาะ "แจ้งลาซ้อม")

## 📖 คู่มือวิธีการใช้งานระบบฉบับสมบูรณ์ (Complete User Manual)

### 3.1 การเข้าสู่ระบบและการเปิดสโมสรใหม่ (Authentication & Club Setup)

#### การเข้าสู่ระบบ (Login)
1. ไปที่หน้า `/login`
2. กรอก **Username** และ **รหัสผ่าน** ของท่าน จากนั้นกด **"เข้าสู่ระบบ"**
3. **1-Click Fast Login Pills (สำหรับทดสอบ):** บนหน้าล็อกอินมีปุ่มชิปลัดให้แตะล็อกอินด้วยบัญชีทดสอบได้ทันที:
   - ⚡ **โค้ชอาร์ม:** ผู้ดูแลระบบ WAVON FC (`arm` / `123456`)
   - ⚽ **คนเช็คชื่อ WAVON:** โค้ชสนาม WAVON FC (`coach_wavon` / `pass1234`)
   - 🏃 **คนเช็คชื่อ THUNDER:** โค้ช THUNDER CLUB (`coach_thunder` / `pass1234`)
   - 👑 **ผู้ดูแลระบบกลาง:** Super Admin (`admin` / `admin1234`)

#### การลงทะเบียนเปิดสโมสรใหม่ (Coach Self-Registration)
1. หากยังไม่มีสโมสร ให้แตะที่ลิงก์ **"ลงทะเบียนเปิดสโมสรใหม่"** ที่หน้า `/register`
2. กรอกข้อมูลให้ครบถ้วน:
   - **ชื่อสโมสร / ทีม:** เช่น `BANGKOK YOUTH FC` หรือ `SMASH BADMINTON ACADEMY`
   - **ชื่อผู้ฝึกสอน:** ชื่อ-นามสกุล หรือชื่อเล่นโค้ช
   - **Username โค้ช:** บัญชีสำหรับใช้เข้าสู่ระบบ (ตัวอักษรภาษาอังกฤษ/ตัวเลข)
   - **รหัสผ่าน & ยืนยันรหัสผ่าน:** กำหนดรหัสผ่านความยาวอย่างน้อย 4 ตัวอักษร
3. กดปุ่ม **"เปิดสโมสรและเริ่มใช้งานทันที"** ระบบจะสร้างสโมสรและเข้าสู่ระบบให้อัตโนมัติ

### 3.2 การจัดการทะเบียนนักกีฬา (Athlete Management & Batch Import)

ระบบรองรับการเพิ่มนักกีฬา 2 รูปแบบ ทั้งการเพิ่มทีละคนและการนำเข้าเป็นชุดจากข้อความแชท:

#### วิธีที่ 1: เพิ่มทีละคน (Single Athlete)
1. ไปที่เมนู **"นักกีฬา"** (`/athletes`)
2. เลือกแท็บ **"ทีละคน"**
3. กรอก **ชื่อ-นามสกุล**, **รหัสนักกีฬา** (หากไม่กรอก ระบบจะรัน `ATH-001` ให้อัตโนมัติ), และ **เบอร์โทรศัพท์** (ไม่บังคับ)
4. กดปุ่ม **"+ บันทึกนักกีฬา"**

#### วิธีที่ 2: วางรายชื่อทีละชุดในคลิกเดียว (Bulk / Batch Import - แนะนำ)
1. ไปที่เมนู **"นักกีฬา"** (`/athletes`) เลือกแท็บ **"นำเข้าเป็นชุด"**
2. คัดลอกรายชื่อจากกลุ่ม LINE, WhatsApp หรือคอลัมน์ใน Excel เช่น:
   ```text
   1. น้องต้น #10 0812345678
   2) น้องเจ เบอร์ 7
   3. น้องมิว
   - น้องบิว 0899998888
   ```
3. นำมาวางลงในช่องข้อความ **Smart Roster Parser** จะทำการ:
   - ตัดตัวเลขลำดับ (`1.`, `2)`, `-`, `•`) ออกให้อัตโนมัติ
   - ดึงเบอร์โทรศัพท์และเบอร์เสื้ออัตโนมัติ
   - ลบอักขระล่องหนและช่องว่างซ้ำซ้อน
4. ตรวจสอบจำนวนรายชื่อที่ตรวจพบในแถบสีเขียว แล้วกดปุ่ม **"บันทึกรายชื่อทั้งหมดเป็นชุด"**

#### การค้นหาและแก้ไขสถานะนักกีฬา
- **ค้นหาทันที:** พิมพ์ชื่อ รหัส หรือเบอร์โทรในช่องค้นหา
- **ตัวกรองสถานะ:** กรองดูเฉพาะนักกีฬา `ACTIVE` (ปกติ) หรือ `INACTIVE` (พักการซ้อม/ลาออก)
- **ประวัติรายบุคคล:** แตะที่ชื่อนักกีฬาเพื่อดูสถิติอัตราการเข้าซ้อมย้อนหลัง และกราฟประวัติการเช็คชื่อ

### 3.3 การสร้างและจัดการรอบการฝึกซ้อม (Training Sessions & Schedules)

การฝึกซ้อมสามารถสร้างได้ทั้งแบบรอบเดี่ยวและตารางซ้อมประจำ:

1. ไปที่เมนู **"รอบซ้อม"** (`/sessions`)
2. แตะปุ่ม **"+ สร้างรอบการฝึกซ้อม"**
3. กำหนดรายละเอียด:
   - **ชื่อหัวข้อการฝึกซ้อม:** เช่น `ซ้อมทักษะเฉพาะตำแหน่ง`, `อุ่นเครื่องแท็กติกทีม`
   - **วันที่ซ้อม:** เลือกวันที่มีการฝึกซ้อม
   - **ช่วงเวลาซ้อม:** กำหนดเวลาเริ่ม - เวลาเลิก (เช่น `17:00` ถึง `19:00` น.)
4. กด **"บันทึกรอบการซ้อม"**

> 💡 **ตารางซ้อมประจำ (Recurring Multi-Session):**  
> สามารถตั้งรอบซ้อมล่วงหน้าได้หลายรอบในวันเดียวกัน เช่น รอบเช้า (06:00–08:00) และรอบเย็น (17:00–19:00) เมื่อนักกีฬาสแกน QR ระบบจะจับคู่รอบซ้อมที่กำลังเปิดอยู่ตามเวลาจริงให้อัตโนมัติ

### 3.4 สถาปัตยกรรมป้าย QR ถาวรประจำสนาม (Permanent QR-Centric Architecture)

ลืมความยุ่งยากของการสร้าง QR ใหม่ทุกครั้งที่ซ้อมไปได้เลย ด้วยระบบ **Permanent QR ประจำสนาม**:

1. ไปที่เมนู **"รอบซ้อม"** (`/sessions`)
2. แตะปุ่ม **"🖨️ พิมพ์ป้าย QR สนาม (A4)"**
3. หน้าต่างพิมพ์เอกสารพร้อมใช้งานจะแสดงขึ้นในดีไซน์มาตรฐานสโมสร:
   - โลโก้และชื่อสโมสร
   - QR Code ความละเอียดสูงระดับเวกเตอร์ (Vector SVG) คมชัด สแกนติดง่ายแม้ระยะไกล
   - คำแนะนำ 3 ขั้นตอนสำหรับนักกีฬา
4. กดสั่งพิมพ์บนกระดาษ A4 เคลือบพลาสติก แล้วนำไปติดที่ทางเข้า ประตูสนาม หรือบอร์ดประชาสัมพันธ์
5. **ความยืดหยุ่นสูงสุด:** หากมีการเลื่อนเวลาหรือเปลี่ยนหัวข้อซ้อม โค้ชสามารถกดแก้ไขในระบบได้ทันที นักกีฬายังคงสแกนป้ายเดิมริมสนามได้ 100% โดยไม่ต้องพิมพ์ป้ายใหม่

### 3.5 ขั้นตอนการเช็คชื่อริมสนาม & การแจ้งลาซ้อม (Pitch Check-In & Leave Notice)

#### ขั้นตอนสำหรับนักกีฬา / ผู้ปกครอง
1. เดินมาถึงสนาม เปิดกล้องมือถือ หรือเปิดแอป **LINE** กดสแกนป้าย QR ประจำสนาม
2. หน้าเว็บเช็คชื่อของสโมสรจะเปิดขึ้นทันที (แสดงชื่อรอบซ้อมและเวลาปัจจุบัน)
3. **การเช็คชื่อเข้าซ้อม (มา):**
   - พิมพ์ค้นหารหัสหรือชื่อของตนเองในช่องค้นหา
   - แตะที่การ์ดชื่อตนเอง แล้วกดปุ่มเขียว **"✓ ยืนยันเช็คชื่อ"**
   - ระบบจะบันทึกผลทันที พร้อมแสดงแถบสีเขียวและลำดับการมาถึงสนาม (เช่น *มาถึงสนามเป็นคนที่ #3*)
   - นักกีฬาคนถัดไปสามารถสแกนหรือค้นหาชื่อเพื่อเช็คชื่อต่อได้ทันทีโดยไม่มีหน้าต่างเด้งขวาง
4. **การแจ้งลาซ้อม (ลา):**
   - แตะที่แท็บ **"แจ้งลาซ้อม"**
   - แตะชื่อตนเอง แล้วเลือกเหตุผลด่วน (*ลาป่วย, ติดเรียน/ติดสอบ, ติดธุระครอบครัว, บาดเจ็บ*) หรือพิมพ์ระบุเหตุผล
   - กดยืนยัน ระบบจะบันทึกสถานะ "ลา" ให้โค้ชรับทราบล่วงหน้าทันที

#### สำหรับโค้ชควบคุมริมสนาม (`/sessions/[id]`)
- **Pitch Live View:** โค้ชสามารถเปิดหน้ารอบซ้อมบนมือถือหรือ iPad ตั้งบนขาตั้งริมสนาม เพื่อดูยอดสด (Live Headcount) นักกีฬาที่เช็คชื่อแล้วจะแสดงเป็นสีเขียวเรียลไทม์
- **แก้ไขสถานะสด:** หากนักกีฬาลืมเอามือถือมา โค้ชสามารถแตะเปลี่ยนสถานะ มา/ขาด/ลา ได้ด้วยตนเองทันที
- **การตัดยอดอัตโนมัติ:** เมื่อถึงเวลาสิ้นสุดรอบซ้อม (`endTime`) ระบบจะทำการปิดรอบและเปลี่ยนสถานะนักกีฬาที่ยังไม่ได้เช็คชื่อให้เป็น **"ขาดซ้อม (ABSENT)"** โดยอัตโนมัติ

### 3.6 แดชบอร์ดวิเคราะห์สถิติ & รายงาน Excel (Analytics & Excel Export)

แดชบอร์ดหลัก (`/`) ให้ข้อมูลเชิงลึกแบบ Real-time เพื่อการประเมินวินัยและการพัฒนาทีม:

- **คะแนนความสม่ำเสมอรวม (Overall Attendance Rate):** คำนวณจากสูตร:
  $$\text{Attendance Rate} = \frac{\text{จำนวนครั้งที่มา}}{\text{รอบซ้อมทั้งหมด} - \text{จำนวนครั้งที่ลา}} \times 100$$
  *(การลาอย่างถูกต้องจะไม่ถูกหักคะแนนวินัย)*
- **ดัชนีความพร้อมสโมสร (Club Readiness Index):**
  - **Grade A (85%+):** ยอดเยี่ยม ระดับแข่งขันสูง วินัยทีมสูงมาก
  - **Grade B+ (75-84%):** ดีมาก มีความสม่ำเสมอต่อเนื่อง
  - **Grade B (60-74%):** มาตรฐานปกติ มีบางส่วนควรสนับสนุนเพิ่ม
  - **Grade C (50-59%):** ปานกลาง มีการขาดซ้อมสะสม ควรพูดคุยรายบุคคล
  - **Grade D (<50%):** ต้องติดตามเร่งด่วน ขาดซ้อมบ่อย
- **Today's Active Session Banner:** แบนเนอร์ทางลัดพิเศษเมื่อมีรอบซ้อมในวันนั้น เพื่อให้โค้ชเปิดดูยอดและเช็คชื่อได้ในคลิกเดียว
- **5-Dot Attendance Streak (`● ● ● ● ○`):** จุดสัญลักษณ์ความสม่ำเสมอในตารางและบนมือถือ ช่วยให้โค้ชกวาดสายตาดูประวัติ 5 นัดล่าสุดได้ทันที
- **ดาวน์โหลดรายงาน Excel (One-Click Export):** แตะปุ่ม **"📥 ดาวน์โหลด Excel"** เพื่อรับไฟล์ตารางสรุปสถิติการเข้าซ้อม สัดส่วนมา/ขาด/ลา ของนักกีฬาทุกคน นำไปรายงานผู้ปกครองหรือผู้บริหารสโมสรได้ทันที

## 🏗️ คู่มือสำหรับนักพัฒนาและการติดตั้ง (Developer & Architecture Guide)

### สแต็กเทคโนโลยี (Technology Stack)
- **Framework:** [Next.js 16.3 (App Router)](https://nextjs.org/) with React 19
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) with PostCSS
- **ORM & Database:** [Drizzle ORM](https://orm.drizzle.team/) with SQLite / Turso LibSQL (WAL Mode)
- **Authentication:** Bcrypt Password Hashing + Signed HMAC Cookies + Multi-tenant Session Isolation
- **Testing:** [Vitest](https://vitest.dev/) (In-memory SQLite Isolated Test Runner)
- **Hosting:** [Render.com](https://render.com/) (Continuous Deployment from `main`)

### คำสั่งสำหรับการพัฒนาในเครื่อง (Local Setup)

```bash
# 1. ติดตั้ง Dependencies ทั้งหมด
npm install

# 2. รันเซิร์ฟเวอร์สำหรับพัฒนา (Development Server)
npm run dev
# เข้าใช้งานที่: http://localhost:3000

# 3. รันชุดทดสอบความถูกต้องอัตโนมัติ (62 tests passing)
npx vitest run

# 4. ทดสอบคอมไพล์ Production Build
npm run build

# 5. รันสคริปต์จำลองข้อมูลทดสอบ
npm run simulate
```
