# 🏅 WAVON — ระบบเช็คชื่อและเก็บสถิตินักกีฬาข้างสนาม (v2.9.0)

> สร้างขึ้นเพื่อช่วยโค้ชและอคาเดมีกีฬา เลิกปวดหัวกับการจดชื่อลงกระดาษหรือเช็คชื่อในไลน์  
> เปลี่ยนมาให้นักกีฬายิง QR Code เช็คชื่อเองริมสนามใน 2 วินาที สรุปสถิติและโหลดเป็น Excel ส่งผู้ปกครองได้ทันที

---

## 💡 ที่มาของระบบนี้ (ทำไมถึงทำขึ้นมา?)

ใครที่เคยคุมเด็กซ้อมกีฬา ไม่ว่าจะเป็นกีฬาชนิดไหน แบดมินตัน บาสเกตบอล ว่ายน้ำ วอลเลย์บอล เทควันโด กรีฑา หรือกีฬาประเภททีม คงเคยเจอปัญหาพวกนี้เหมือนกัน:
- **ถือแฟ้มกระดาษเดินเช็คชื่อ:** พอฝนตก ลมพัด เหงื่อหยดใส่ กระดาษเปียกขาด ปากกาหมึกเยิ้ม
- **พิมพ์เช็คชื่อในกลุ่มไลน์:** ผู้ปกครองพิมพ์ตอบกันยาวเป็นพรืด ข้อมูลตีกัน มั่วไปหมดตอนมีคนขอลา
- **เด็กมาสาย หรือจำรหัสไม่ได้:** มายืนออกันหน้าสนาม ทำให้เริ่มซ้อมช้า
- **สรุปรายงานสิ้นเดือนส่งผู้ปกครอง:** โค้ชต้องมานั่งนับวันย้อนหลังทีละคน ปวดหัวและเสียเวลาคุมซ้อมมาก

ระบบ **WAVON** เลยถูกสร้างขึ้นมาแก้จุดนี้แบบตรงไปตรงมา: **"พิมพ์ป้าย QR แปะข้างสนามใบเดียวจบ เด็กเดินมากดยิงชื่อตัวเอง โค้ชยืนดูยอดสดบนมือถือ สิ้นเดือนกดโหลด Excel ได้เลย"**

## 👥 สิทธิ์การใช้งานในระบบ

ระบบนี้แบ่งการทำงานเป็น 3 กลุ่มชัดเจน:

1. **นักกีฬา / ผู้ปกครอง:**
   - **ไม่ต้องสมัครสมาชิก ไม่ต้องมีรหัสผ่าน**
   - แค่เปิดกล้องมือถือหรือสแกนจากแอป LINE ยิงป้าย QR ริมสนาม
   - ค้นหาชื่อตัวเองแล้วกดเช็คชื่อ หรือกด "แจ้งลาซ้อม" พร้อมใส่เหตุผลได้เลย
2. **โค้ชประจำสโมสร (Coach):**
   - ล็อกอินเข้ามาจัดการรายชื่อนักกีฬาในทีม
   - สร้างตารางซ้อมประจำสัปดาห์
   - พิมพ์ป้าย QR ขนาด A4 ประจำสนาม
   - ดูยอดนักกีฬาที่มาซ้อมแบบสดๆ ข้างสนาม และกดโหลดไฟล์ Excel สรุปรายเดือน
3. **ผู้ดูแลระบบ (Super Admin):**
   - จัดการภาพรวม ดูแลและสลับดูข้อมูลได้ทุกสโมสร
   - มีปุ่มโหลดข้อมูลจำลอง (Demo) เอาไว้ทดลองเล่นหรือสาธิตระบบให้คนอื่นดู

## 📖 คู่มือการใช้งานจริงทีละขั้นตอน

### 1. การเข้าใช้งาน & ลงทะเบียนสโมสรใหม่

- **สำหรับทดลองระบบ (1-Click Fast Login):**
  ที่หน้า `/login` จะมีปุ่มลัดให้กดล็อกอินเข้าดูระบบได้ทันทีโดยไม่ต้องพิมพ์รหัส:
  - **โค้ชอาร์ม (WAVON):** บัญชีตัวอย่างสโมสร มีข้อมูลครบพร้อมดู
  - **โค้ช THUNDER:** บัญชีตัวอย่างอีกสโมสร เพื่อทดสอบการแยกข้อมูล
  - **ผู้ดูแลระบบกลาง (Admin):** บัญชีแอดมินสำหรับคุมทุกสโมสร
- **สำหรับเปิดสโมสรของตัวเองจริง:**
  กดที่ **"เปิดสโมสรใหม่สำหรับโค้ช"** (`/register`) กรอกชื่อทีม ชื่อโค้ช ตั้งรหัสผ่าน แล้วกดเริ่มใช้งานได้ทันที แต่ละสโมสรจะมีฐานข้อมูลแยกกัน ไม่ปะปนกับทีมอื่น

---

### 2. นำเข้ารายชื่อนักกีฬา (ก๊อปจากไลน์มาแปะทีเดียว)

ไม่ต้องมานั่งพิมพ์ชื่อเด็กทีละคนให้เมื่อยนิ้ว:

1. ไปที่เมนู **"นักกีฬา"** (`/athletes`) แล้วเลือกแท็บ **"นำเข้าเป็นชุด"**
2. ไปก๊อปปี้รายชื่อเด็กจากกลุ่ม LINE หรือจากไฟล์ Excel มาวางลงในช่องได้เลย เช่น:
   ```text
   1. น้องต้น เบอร์ 10 โทร 0812345678
   2. น้องเจ #7
   3) น้องมิว 089-999-8888
   - น้องพีช
   ```
3. ระบบจะตัดตัวเลขลำดับหน้าชื่อ ดึงเบอร์โทร และดึงหมายเลขประจำตัวให้อัตโนมัติ พร้อมตั้งรหัสนักกีฬาให้เอง (`ATH-001`, `ATH-002`, ...)
4. ตรวจดูความถูกต้อง แล้วกดปุ่มเขียว **"บันทึกรายชื่อทั้งหมดเป็นชุด"** รายชื่อทั้งหมดจะเข้าระบบทันทีในคลิกเดียว

---

### 3. สร้างรอบซ้อม & พิมพ์ป้าย QR ประจำสนาม

แนวคิดของระบบนี้คือ **"ป้ายเดียวใช้ได้ตลอดฤดูกาล"**:

1. ไปที่เมนู **"รอบซ้อม"** (`/sessions`)
2. กดปุ่ม **"+ สร้างรอบการฝึกซ้อม"** กำหนดวัน เวลาเริ่ม-เวลาเลิก (เช่น วันนี้ 17:00 - 19:00 น.)
3. กดปุ่ม **"พิมพ์ป้าย QR สนาม (A4)"**
4. ระบบจะทำหน้าป้ายพร้อมพิมพ์ให้อัตโนมัติ มีโลโก้สโมสรและ QR Code คมชัด
5. **เอาไปปริ้นท์ใส่กระดาษ A4 เคลือบพลาสติกใส แปะไว้ตรงทางเข้าสนามหรือบอร์ดประชาสัมพันธ์**
6. **ข้อดี:** วันหลังต่อให้เปลี่ยนเวลาซ้อม หรือเพิ่มรอบซ้อมเช้า-เย็น **ไม่ต้องพิมพ์ป้ายใหม่** เด็กยังคงสแกนป้ายเดิมริมสนามได้ตลอด ระบบจะรู้เองว่าตอนนี้กำลังอยู่ในรอบซ้อมไหน

---

### 4. วันซ้อมจริง: ขั้นตอนเช็คชื่อ & แจ้งลาข้างสนาม

#### 📱 ฝั่งนักกีฬา (เดินมาถึงสนาม):
1. หยิบมือถือขึ้นมา เปิดกล้องหรือสแกนผ่านแอป LINE ยิงป้าย QR ประจำสนาม
2. หน้าเช็คชื่อจะเปิดขึ้นมาทันที:
   - **กรณีมาซ้อม:** พิมพ์ชื่อหรือรหัสตัวเองในช่องค้นหา -> กดที่ชื่อตัวเอง -> กดปุ่ม **"ยืนยันเช็คชื่อ"**
   - ระบบจะบันทึกทันที ขึ้นแถบเขียวแจ้งว่า *"เช็คชื่อเรียบร้อย คุณมาถึงสนามเป็นคนที่ #3"*
   - พอเช็คเสร็จ หน้าจอจะพร้อมให้นักกีฬาคนถัดไปค้นหาชื่อเช็คชื่อต่อได้ทันที โดยไม่มีป๊อปอัปมาบังแถว
   - หากเคยสแกนในเครื่องนี้มาก่อน ระบบจะจำชื่อไว้ให้ ครั้งต่อไปแค่กดปุ่ม **"1-Click เช็คชื่อทันที"** ใน 1 วินาที
3. **กรณีลาซ้อม (มาไม่ได้):**
   - สลับไปที่แท็บ **"แจ้งลาซ้อม"**
   - กดเลือกชื่อตัวเอง แล้วเลือกเหตุผลด่วน (ลาป่วย, ติดสอบ, ธุระครอบครัว, บาดเจ็บ) แล้วกดยืนยัน
   - ระบบจะบันทึกเป็น "ลา" ให้โค้ชเห็นล่วงหน้าทันที

#### ⏱️ ฝั่งโค้ช (ยืนคุมซ้อม):
- โค้ชเปิดหน้าหน้ารอบซ้อม (`/sessions/[id]`) บนมือถือหรือตั้งแท็บเล็ตไว้ข้างสนาม
- จะเห็นรายชื่อเด็กที่มาแล้วเป็นแถบสีเขียวเรียลไทม์ และยอดตัวเลขสรุปว่ามากี่คน
- **ถ้าเด็กคนไหนลืมเอามือถือมา:** โค้ชกดแตะเปลี่ยนสถานะเป็น "มาซ้อม" ให้เด็กได้โดยตรงจากหน้าจอนี้เลย
- **เมื่อหมดเวลาซ้อม:** ระบบจะทำการปิดรอบซ้อม และเปลี่ยนสถานะเด็กที่ไม่ได้สแกนชื่อให้เป็น **"ขาดซ้อม"** ให้อัตโนมัติ โค้ชไม่ต้องมานั่งไล่ติ๊กคนขาดเองตอนดึก

### 5. ดูสถิติ & ส่งออกรายงาน Excel ระดับมืออาชีพ (แยกทั้งหมด / วัน / เดือน / ปี)

ที่หน้าแรก (Dashboard):
- **คะแนนความพร้อมสโมสร (Club Readiness Index):** สรุปภาพรวมวินัยของทีมเป็นเกรด A ถึง D
- **เปอร์เซ็นต์ความสม่ำเสมอ (Attendance Rate):** คิดจากสูตร:
  $$\text{เปอร์เซ็นต์การมา} = \frac{\text{จำนวนครั้งที่มาซ้อม}}{\text{รอบซ้อมทั้งหมด} - \text{จำนวนครั้งที่ลาอย่างถูกต้อง}} \times 100$$
  *(เด็กคนไหนแจ้งลาล่วงหน้าอย่างถูกต้อง ระบบจะไม่นำมาหักคะแนนวินัย เพื่อความยุติธรรมกับน้องๆ)*
- **จุดสถิติ 5 นัดล่าสุด (`● ● ● ● ○`):** โค้ชกวาดสายตาดูการ์ดนักกีฬา จะเห็นทันทีว่าคนไหนมาซ้อมสม่ำเสมอ หรือคนไหนเริ่มขาดซ้อมติดๆ กัน
- **หน้าต่างส่งออกรายงาน Excel (Export Modal):** กดปุ่ม **"ส่งออกรายงาน (Excel / CSV)"** จะมีหน้าต่างให้เลือกช่วงเวลาอย่างยืดหยุ่น:
  - 🌐 **ทั้งหมด (All Time):** สรุปประวัติทั้งหมดตั้งแต่เปิดสโมสร
  - 📅 **วันนี้ (Today):** สรุปเฉพาะรอบซ้อมของวันนี้
  - 📆 **ประจำเดือน (Monthly):** สรุปของเดือนปัจจุบัน หรือเดือนที่แล้ว
  - 🗓️ **ประจำปี (Yearly):** สรุปภาพรวมรายปี
  - ⚙️ **กำหนดเอง (Custom Range):** ระบุวันเริ่มต้นและสิ้นสุด
- **ไฟล์ Excel (.xlsx) แยก 4 แผ่นงาน (Worksheets):**
  1. **ภาพรวมสโมสร:** บัตร KPI, สถิติสรุปภาพรวมผู้บริหาร, ตารางแนวโน้มรายปี
  2. **สรุปรายเดือน:** ตารางสรุปยอดการซ้อม มา/ขาด/ลา และ % ความสม่ำเสมอแยกตามแต่ละเดือน
  3. **สรุปรายวัน:** ประวัติการฝึกซ้อมแยกแต่ละรอบอย่างละเอียด
  4. **สถิตินักกีฬารายบุคคล:** รายชื่อนักกีฬาทุกคน เรียงลำดับยอด มา/ขาด/ลา พร้อมเกรดประเมิน และแถวผลรวมท้ายตาราง
  *(ตารางจัดสไตล์หัวสีสวยงาม ล็อกหัวตาราง ปรับความกว้างคอลัมน์อัตโนมัติ พร้อมรองรับภาษาไทย 100%)*

### 6. เมนูสำหรับแอดมิน (Super Admin)

ถ้าล็อกอินด้วยบัญชี Admin (`arm` หรือ `admin`):
- จะมีเมนู **"แผงควบคุม"** (`/admin`) เพิ่มขึ้นมา
- สามารถดูรายชื่อทุกสโมสรในระบบ และกดปุ่ม **"สลับเข้าดูสโมสรนี้"** เพื่อเข้าไปช่วยโค้ชดูข้อมูลได้
- มีเครื่องมือ **Demo Tools:**
  - กดปุ่ม **"โหลดข้อมูลตัวอย่าง (Demo)"** เพื่อสร้างนักกีฬาจำลอง 32 คน และประวัติการซ้อม 8 รอบ เอาไว้ซ้อมใช้งานระบบ
  - มีปุ่ม **"ล้างข้อมูล Demo"** เพื่อลบข้อมูลจำลองทิ้งอย่างปลอดภัย โดยไม่ไปกระทบกับข้อมูลจริงของโค้ช

## 🎯 ทริคและข้อแนะนำการใช้งานข้างสนาม (จากประสบการณ์จริง)

1. **การติดป้าย QR Code:**
   - แนะนำให้พิมพ์ลงกระดาษ A4 แล้วนำไปเคลือบพลาสติกใสกันน้ำ
   - ติดไว้ที่ความสูงระดับอก (ประมาณ 1.3 - 1.5 เมตร) ในจุดที่มีแสงสว่างพอ เช่น ประตูทางเข้าสนาม หรือข้างซุ้มม้านั่งสำรอง
   - ถ้าทีมมีเด็กเกิน 30-40 คน ให้พิมพ์ติดไว้ 2 จุด จะได้ไม่ต้องยืนต่อคิวกัน
2. **การแชร์ลิงก์ให้ผู้ปกครองแจ้งลาล่วงหน้า:**
   - ในหน้ารอบซ้อม โค้ชสามารถกดปุ่ม **"คัดลอกส่ง LINE"** แล้วนำลิงก์ไปปักหมุดไว้ใน "โน้ต" ของกลุ่ม LINE ผู้ปกครอง
   - วันไหนที่เด็กป่วยหรือติดเรียน ผู้ปกครองสามารถกดลิงก์นั้นจากที่บ้านเพื่อแจ้งลาล่วงหน้าได้เลย สะดวกมาก
3. **ระบบป้องกันเด็กแอบเช็คชื่อจากที่บ้าน (Pitch Anti-Cheat):**
   - ลิงก์ที่เปิดผ่านการแชร์ทางไลน์จะกดได้เฉพาะปุ่ม "แจ้งลาซ้อม" เท่านั้น
   - ปุ่ม "เช็คชื่อเข้าซ้อม" จะกดได้ก็ต่อเมื่อมายืนสแกนจากป้าย QR จริงริมสนามเท่านั้น ป้องกันเด็กเนียนกดเช็คชื่อจากที่บ้าน

- **จัดตารางสไตล์มืออาชีพ:** ตารางหัวสีกรมท่าเข้ม สลับสีแถวให้อ่านสบายตา ล็อกหัวตารางเวลาเลื่อนจอ และปรับขนาดคอลัมน์อัตโนมัติ
- **เพิ่มระบบสรุปสถิติรายเดือนและรายปี:** คำนวณสรุปยอดการซ้อมของสโมสรแยกเป็นแต่ละเดือนและแต่ละปีอย่างแม่นยำ

### 🛡️ v2.8.1 — เสริมความปลอดภัยและการรองรับการกดพร้อมกัน

## 💻 สำหรับนักพัฒนา (Developer Guide)

### เทคโนโลยีที่ใช้เบื้องหลัง
- **Framework:** Next.js 16.3 (App Router) + React 19
- **CSS / UI:** Tailwind CSS v4
- **Database & ORM:** SQLite / Turso LibSQL + Drizzle ORM
- **Testing:** Vitest (มีชุดทดสอบครอบคลุม 62 รายการ)
- **Deployment:** Render.com (ตั้ง Auto-Deploy จากกิ่ง `main`)

### คำสั่งสำหรับรันในเครื่อง

```bash
# 1. ติดตั้งแพ็กเกจ
npm install

# 2. รันระบบสำหรับพัฒนา (Local Dev)
npm run dev
# เปิดเบราว์เซอร์เข้าไปที่: http://localhost:3000

# 3. รันชุดทดสอบอัตโนมัติ (Automated Tests)
npx vitest run

# 4. ทดสอบคอมไพล์สำหรับ Production
npm run build
```
